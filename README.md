
Proyecto de Filtros Digitales

 Descripción
Este proyecto consiste en diseñar e implementar tres tipos de filtros digitales utilizando Python, con la finalidad de analizar señales que contienen ruido y observar cómo cambia su comportamiento después de aplicar los filtros.

Filtros implementados

- Filtro pasa bajos:** permite el paso de frecuencias bajas y reduce las frecuencias altas.
- Filtro pasa altos:** permite el paso de frecuencias altas y reduce las frecuencias bajas.
  Filtro pasa bandas:** permite el paso de frecuencias dentro de un rango específico.

Herramientas utilizadas

- Python.
- NumPy.
- SciPy.
- Matplotlib.
- Google Colab.

Objetivo
Comprender el funcionamiento de los filtros digitales mediante simulaciones y gráficas que permitan comparar las señales originales con las señales filtradas.

Desarrollo del proyecto

Se creó una señal compuesta por diferentes frecuencias y se agregó ruido blanco. Posteriormente, se diseñaron los tres filtros utilizando el método Butterworth y se aplicaron a la señal para observar sus resultados.
 Resultados

Se obtuvieron gráficas de las señales antes y después del filtrado, así como sus respectivas respuestas en frecuencia. Esto permitió identificar cómo trabaja cada filtro y qué frecuencias conserva o reduce.



La realización de este proyecto permitió comprender la importancia de los filtros digitales en el procesamiento de señales ycómo se pueden utilizar para reducir el ruido y analizar diferentes frecuencias.
